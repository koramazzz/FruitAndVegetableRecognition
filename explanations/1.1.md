# Classification Benchmark Explanations (Task 1.1)

## Hyperparameter Selection Methodology

All hyperparameters were determined using **Grid Search with 3-fold Stratified Cross-Validation**. This approach:

1. **Exhaustively searches** all combinations in the predefined parameter grid
2. **Stratified folds** ensure each fold preserves the class distribution
3. **Selects the best configuration** based on mean cross-validation accuracy

The specific hyperparameter ranges were chosen based on common practices:
- **C (regularization)**: `[0.1, 1.0, 10.0]` — covers under-regularized to over-regularized spectrum
- **k-NN neighbors**: `[3, 5, 9]` — odd numbers to avoid ties, covering local to broader neighborhoods

## Classifiers and Their Configurations

### 1. Logistic Regression (Linear)
- **Solver**: L-BFGS (efficient for multiclass problems)
- **Penalty**: L2 regularization to prevent overfitting
- **C parameter**: Inverse of regularization strength; higher C = less regularization

### 2. Logistic Regression with Non-linear Transformation
Uses **Random Fourier Features (RBFSampler)** to approximate the RBF kernel in feature space.

The transformation maps input features to a higher-dimensional space where linear classification can capture non-linear decision boundaries:

$$\phi(x) \approx \sqrt{\frac{2}{D}} \cos(\omega^T x + b)$$

where $\omega$ is sampled from a Gaussian distribution with variance $\gamma$.

- **gamma**: Controls the width of the RBF kernel (smaller = wider)
- **n_components**: Dimensionality of the transformed feature space (300 or 800)

### 3. Soft-Margin SVM (Linear)
Standard SVM with a **linear kernel** that allows some misclassifications via slack variables:

$$\min_{w,b,\xi} \frac{1}{2}\|w\|^2 + C \sum_{i=1}^{n} \xi_i$$

- **C parameter**: Trade-off between maximizing margin and minimizing classification error
- Soft-margin: The $\xi_i$ slack variables allow points to be on the wrong side of the margin

### 4. Soft-Margin SVM with Kernel Trick (RBF)
Uses the **Radial Basis Function (RBF) kernel**:

$$K(x, x') = \exp(-\gamma \|x - x'\|^2)$$

- **gamma='scale'**: Automatically computed as $\gamma = \frac{1}{n_{features} \cdot \text{Var}(X)}$
- **gamma=0.01, 0.05**: Manual values for finer control
- The kernel trick implicitly maps data to infinite-dimensional space without explicit computation

### 5. k-Nearest Neighbors (k-NN)
Non-parametric classifier that assigns labels based on majority vote of k nearest training samples.

- **n_neighbors**: Number of neighbors to consider
- **weights='uniform'**: All neighbors contribute equally
- **weights='distance'**: Closer neighbors have more influence
- **metric='minkowski'**: Generalized distance (p=2 gives Euclidean distance)

### 6. Naive Bayes (Gaussian)
Probabilistic classifier assuming features are independent and normally distributed:

$$P(y|x_1,...,x_n) \propto P(y) \prod_{i=1}^{n} P(x_i|y)$$

- **var_smoothing**: Portion of largest variance added to all variances for numerical stability

### 7. Random Forest
Ensemble of decision trees trained on bootstrap samples with random feature subsets.

- **n_estimators**: Number of trees in the forest (200, 400)
- **max_depth**: Maximum tree depth (None = unlimited, 20, 40)
- **max_features**: Number of features considered at each split ('sqrt', 'log2')
- **min_samples_leaf**: Minimum samples required at leaf nodes (regularization)
